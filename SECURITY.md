# Security Policy

## Supported Versions

The following versions currently receive security updates.

| Version | Supported |
|----------|-----------|
| 1.x | ✅ Yes |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** create a public GitHub Issue.

Instead, include:

- Description of the vulnerability
- Steps to reproduce
- Expected behavior
- Actual behavior
- Potential impact
- Screenshots or logs (if available)

Security reports will be reviewed and addressed as quickly as possible.

---

## Security Best Practices

- Keep Python and project dependencies updated.
- Never commit API keys, passwords, or secrets.
- Store sensitive information securely.
- Install packages only from trusted sources.
- Keep your local development environment updated.

---

## Out of Scope

The following are generally **not** considered security vulnerabilities:

- Documentation improvements
- UI suggestions
- Feature requests
- Performance optimizations
- Typographical errors

---

## Responsible Disclosure

Please report vulnerabilities responsibly and allow time for investigation before public disclosure.

Thank you for helping improve the security of PortfolioPilot AI.
