# PortfolioPilot AI

An AI-powered stock portfolio analysis platform built with Python and Streamlit. PortfolioPilot AI helps investors analyze portfolio performance, monitor asset allocation, evaluate risk, and visualize investment growth through interactive dashboards.

## Features

- 📈 Portfolio Performance Analysis
- 💼 Stock Holdings Dashboard
- 📊 Asset Allocation Visualization
- 📉 Profit & Loss Tracking
- 📅 Investment Timeline
- ⚖️ Risk Analysis
- 📤 CSV Export
- 📊 Interactive Charts
- ⚡ Modern Streamlit Interface

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
